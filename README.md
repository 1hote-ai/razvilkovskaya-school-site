# МБОУ «Развилковская СОШ с УИОП»

Современный презентационный сайт МБОУ «Развилковская средняя общеобразовательная школа с углубленным изучением отдельных предметов».

## О проекте

Это не официальный портал с документами и расписаниями.  
Это презентационный сайт, который визуально показывает пространство, атмосферу, образовательную среду, достижения и жизнь школы.

## Стек

| Технология | Назначение |
|---|---|
| **Vite** | Сборщик — быстрый dev-сервер и оптимизированная production-сборка |
| **React 19** | UI-библиотека |
| **TypeScript** | Типизация |
| **SCSS Modules** | Стили с изоляцией, переменными и миксинами |
| **Oxlint** | Линтинг |

## Структура

```
src/
├── components/        # React-компоненты (папка на компонент)
│   └── Header/
│       ├── Header.tsx
│       └── Header.module.scss
├── styles/            # Глобальные стили и токены
│   ├── variables.scss
│   ├── mixins.scss
│   ├── reset.scss
│   └── global.scss
├── assets/            # Статические ресурсы (шрифты, изображения)
├── App.tsx
└── main.tsx
```
